## 1.3.4.3 PROFINET IO-Gerätespezifikationen

<br>

##### Protokollmerkmale

| **| Kategorie                   | Spezifikationen                  |**                   | **| Kategorie                   | Spezifikationen                  |**                  |
| :---                       | :---                      |
| Maximale Eingangsbyte-Größe        | 256 Bytes (TP) / 1024 Bytes (Sycon.net)|
| Maximale Ausgangsbyte-Größe        | 256 Bytes (TP) / 1024 Bytes (Sycon.net)|
| E/A-Verbindung (Implicit)         |                          |
| E/A-Verbindung                    |                          |
| Minimale E/A-Zykluszeit         | 1ms                      |
| Kommunikationsgeschwindigkeit                  | 100 Mbit/s               |
| Auto Negotiation           | Nicht unterstützt                   |
| Quick Connect              | Nicht unterstützt                   |
| Topology                   | Tree, Line               |
| DCP                        | Unterstützt                     |


<br>

##### Netzwerkmerkmale

| **| Kategorie                   | Spezifikationen                  |**                   | **| Kategorie                   | Spezifikationen                  |**                  |
| :---                       | :---                      |
| Data Transport Layer       | Ethernet II, IEEE 802.3   |
| Hub                        | Nicht verfügbar                |
| Switch                     | Eingeschränkte Nutzung möglich (erfordert Priority Tagging, LLDP-Unterstützung) |
