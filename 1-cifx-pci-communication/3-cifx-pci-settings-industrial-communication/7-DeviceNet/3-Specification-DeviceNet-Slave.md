#### 1.3.7.3 DeviceNet Slave 规格


<br>

**协议特性**

| **区分**                   | **规格**                  |
| :---                       | :---                      |
| 最大输入字节数        | 255 Bytes                 |
| 最大输出字节数        | 255 Bytes                 |
| IO 连接 (Implicit)         |                           |
| IO 连接                    | Bit Strobe, Change of State, Cyclic, Poll |
| IO 最小 Cycle Time         |                           |
| 通信速度                  | 125～500 Kbit/s          |
| Auto Baud Rate Detection   | 不支持                    |
| Quick Connect              |                          |
| Topology                   |                          |


<br>

**网络特性**

| **区分**                       | **规格**                   |
| :---                           | :---                      |
| Data Transport Layer           | CAN frames                |
| Hub                            | 不适用                  |
| Switch                         | 不适用                  |
