### 1.3.10 EtherNet/IP – Standard-Remote-E/A-Verbindung

<br>

In diesem Kapitel wird erläutert, wie mehrere von unserem Unternehmen ausgewählte Standard-Remote-E/A-Module über den EtherNet/IP-Scanner (Master) angeschlossen werden.

<br>

{% hint style="info" %}
\.      Der EtherNet/IP-Scanner (Master) verwendet CIFX-50 Real Time Ethernet PCI.


\.      Das Remote-E/A-Modul verwendet den Crevis M9289 EtherNet/IP-Netzwerkadapter.
{% endhint %}
