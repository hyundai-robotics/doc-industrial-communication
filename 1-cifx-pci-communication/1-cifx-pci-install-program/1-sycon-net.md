### 1.1.1 SYCON.net安装

“Sycon.net”是Hilscher提供的用于配置PCI通信卡Configuration的程序。

<br>

**1. SYCON.net最新版本下载路径**

{% hint style="info" %}
\.      点击 **[https://hilscher.atlassian.net/](https://hilscher.atlassian.net/wiki/spaces/HILKB/overview?mode=global) -> Software -> SYCON.net**。
{% endhint %}

<br>

![[图1.1.1-1 Sycon.net安装界面]](<../../_assets/1-cifx-pci-communication/1-cifx-pci-install-program/1-Sycon/image_1.png>)

<br>

![[图 1.1.1-2 Sycon.net安装界面]](<../../_assets/1-cifx-pci-communication/1-cifx-pci-install-program/1-Sycon/image_2.png>)

<br>

{% hint style="info" %}
\.      选择最新版本（Current Release）并下载。
{% endhint %}

<br>

![[图 1.1.1-3 Sycon.net 安装界面]](<../../_assets/1-cifx-pci-communication/1-cifx-pci-install-program/1-Sycon/image_3.png>)

<br>

![[图 1.1.1-4 Sycon.net 安装界面]](<../../_assets/1-cifx-pci-communication/1-cifx-pci-install-program/1-Sycon/image_4.png>)

<br>

{% hint style="info" %}
\.      执行所下载的 SYCON.NET Setup.exe 文件以安装程序。
{% endhint %}

<br>

![[图 1.1.1-5 Sycon.net 安装界面]](<../../_assets/1-cifx-pci-communication/1-cifx-pci-install-program/1-Sycon/image_5.png>)

<br>

![[图 1.1.1-6 Sycon.net 安装界面]](<../../_assets/1-cifx-pci-communication/1-cifx-pci-install-program/1-Sycon/image_6.png>)

<br>

{% hint style="info" %}
\.      执行已安装的 SYCON.NET 程序，并确认是否正常完成安装。
{% endhint %}

<br>

![[图 1.1.1-7 Sycon.net 安装界面]](<../../_assets/1-cifx-pci-communication/1-cifx-pci-install-program/1-Sycon/image_7.png>)

<br>


**2. 在现代机器人官网下载程序**

{% hint style="info" %}
\.      依次进入[www.hd-hyundairobotics.com](https://hd-hyundairobotics.com/) -> 工业机器人官网 -> 客户支持 -> 应用软件，下载“**Sycon.net**”。
{% endhint %}

<br>

{% hint style="info" %}
\.      解压 -> 执行 SYCON.NET Setup.exe 文件以安装程序。
{% endhint %}

<br>

{% hint style="info" %}
\.      本公司官网提供的 SYCON.net 程序可能与最新版本不同。
{% endhint %}
