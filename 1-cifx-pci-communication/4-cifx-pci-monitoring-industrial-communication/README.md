# 1.4 CIFX PCI通信监控

“[按照“**1.2 CIFX PCI通信卡安装及设置**”及“**1.3 CIFX PCI通信设置**”流程进行通信设置后，可以在以下屏幕中确认运行情况。](../../1-cifx-pci-communication/2-cifx-pci-mounting-settings-industrial-communication-card/1-PCI-industrial-communication-card.md)” 및 “[按照“**1.2 CIFX PCI通信卡安装及设置**”及“**1.3 CIFX PCI通信设置**”流程进行通信设置后，可以在以下屏幕中确认运行情况。](../../1-cifx-pci-communication/3-cifx-pci-settings-industrial-communication/1-Settings-firmware.md)” 절차를 따라 통신 설정 이후 동작여부를 다음과 같은 화면에서 확인 가능합니다.

触摸*\[服务 > 19: 工业通信监控]**即可进入，在该界面中可以确认已设置的固件信息、通信状态、通信配置状态等。

{% hint style="info" %}
\.      **\.      可以使用\[重启]按钮重启该PCI通信卡的工业通信。** 버튼을 이용하여 해당 PCI 통신 카드의 산업용 통신을 재시작 시킬 수 있습니다.

\.      请检查插槽、固件、设备状态。

\.      对于Master，请确认从站配置及激活从站是否与已配置的从站数量相同。
{% endhint %}
