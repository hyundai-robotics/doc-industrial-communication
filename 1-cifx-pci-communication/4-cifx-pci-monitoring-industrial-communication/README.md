# 1.4 CIFX PCI Communication Monitoring

“[After setting the communication according to the "**1.2 CIFX PCI Communication Card Installation and Settings**" and "**1.3 CIFX PCI Communication Settings**" procedures, you can check the operation status on the following screen.](../../1-cifx-pci-communication/2-cifx-pci-mounting-settings-industrial-communication-card/1-PCI-industrial-communication-card.md)” 및 “[After setting the communication according to the "**1.2 CIFX PCI Communication Card Installation and Settings**" and "**1.3 CIFX PCI Communication Settings**" procedures, you can check the operation status on the following screen.](../../1-cifx-pci-communication/3-cifx-pci-settings-industrial-communication/1-Settings-firmware.md)” 절차를 따라 통신 설정 이후 동작여부를 다음과 같은 화면에서 확인 가능합니다.

You can enter the screen by touching the *\[Service > 19: Industrial Communication Monitoring]** menu, and on this screen you can check the set firmware information, communication status, communication configuration status, etc.

{% hint style="info" %}
\.      **\.      Using the \[Restart] button, you can restart the industrial communication of the PCI communication card.** 버튼을 이용하여 해당 PCI 통신 카드의 산업용 통신을 재시작 시킬 수 있습니다.

\.      Please check the status of the slot, firmware, and device.

\.      For the master, check whether the number of the configured and active slaves matches the number of configured slaves.
{% endhint %}
