# 1.4 CIFX PCI Communication Monitoring

After setting the communication according to the "[**1.2 CIFX PCI Communication Card Installation and Settings**](../../1-cifx-pci-communication/2-cifx-pci-mounting-settings-industrial-communication-card/1-PCI-industrial-communication-card.md)" and "[**1.3 CIFX PCI Communication Settings**](../../1-cifx-pci-communication/3-cifx-pci-settings-industrial-communication/1-Settings-firmware.md)" procedures, you can check the operation status on the following screen.

You can enter the screen by touching the **\[Service > 19: Industrial Communication Monitoring]** menu, and on this screen you can check the set firmware information, communication status, communication configuration status, etc.

{% hint style="info" %}
\.      Using the **\[Restart]** button, you can restart the industrial communication of the PCI communication card.

\.      Please check the status of the slot, firmware, and device.

\.      For the master, check whether the number of the configured and active slaves matches the number of configured slaves.
{% endhint %}
