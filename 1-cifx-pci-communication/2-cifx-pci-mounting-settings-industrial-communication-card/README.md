# 1.2 Installation und Einstellungen der CIFX-PCI-Kommunikationskarte

Für die industrielle Kommunikation ist eine PCI-Kommunikationskarte (von Hilscher) erforderlich. Konfigurieren Sie die Einstellungen der Kommunikationskarte und verdrahten Sie die Anschlüsse entsprechend der erforderlichen Kommunikation.
