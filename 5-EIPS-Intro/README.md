# 5. EtherNet/IP 어댑터

내장형 EtherNet/IP 어댑터에 대한 설명입니다.

## 5.1 Hi6 EtherNet/IP 어댑터
Hi6 로봇제어기는 다양한 종류의 산업용 통신 기능을 제공하고 있습니다. 그 중 EtherNet/IP 어댑터는 별도의 추가 하드웨어가 필요하지 않는 기능입니다. 해당 기능을 사용하기 위해서는 별도의 소프트웨어 라이선스를 구매가 필요합니다. 라이선스 구매는 HD 현대 로보틱스 부품사업팀으로 문의 바랍니다.
