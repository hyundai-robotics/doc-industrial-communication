## 2.1 Hi6 EtherNet/IP适配器

### 2.1.1 介绍
Hi6机器人控制器提供多种工业通信功能。其中，EtherNet/IP适配器是无需额外添加硬件的功能。要使用该功能，就需要购买单独的软件许可证。有关许可证购买的事宜，请联系HD现代机器人零件业务部。 <br>

### 2.1.2 产品规格
|项目|说明|
|------|---|
|网络类型|EtherNet/IP|
|Speed|10/100 Mbps, 1Gbps|
|Input Size Range(bytes)|0 - 240|
|Output Size Range(bytes)|0 - 240|
|Transport Class|Class 1 I/O implicit|
