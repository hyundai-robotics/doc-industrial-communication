# 2. EtherNet/IP适配器

这是关于内置EtherNet/IP适配器的说明。<br>

### 术语
|缩写|说明|
|---------------|------------------------------|
|适配器（Adapter）|从EtherNet/IP扫描器（Scanner）收集Output Data并发送Input Data的设备|
|扫描器（Scanner）|向终端设备（EtherNet/IP适配器）发送Output Data并从中收集Input Data的设备|
|LAN| Local Area Network|
|RPI|Requested Packet Interval（通信周期）|
|PLC|Programmable logic controller|
|T2O|Target to Originator（适配器 -> 扫描器）|
|O2T|Originator to Target（扫描器 -> 适配器）|
