## 2. EtherNet/IP-Adapter

Beschreibung des integrierten EtherNet/IP-Adapters.<br>

**Terminologie**
|Abkürzung|Beschreibung|
|---------------|------------------------------|
|Adapter|Gerät, das Ausgangsdaten vom EtherNet/IP-Scanner erfasst und Eingangsdaten überträgt|
|Scanner|Gerät, das Ausgangsdaten an Endgeräte (EtherNet/IP-Adapter) sendet und Eingangsdaten von diesen erfasst|
|LAN| Local Area Network|
|RPI|Requested Packet Interval – Angefordertes Paketintervall (Kommunikationszyklus)|
|PLC|Programmable logic controller|
|T2O|Target to Originator – Zielgerät an Absender (Adapter -> Scanner)|
|O2T|Originator to Target – Absender an Zielgerät (Scanner -> Adapter)|
