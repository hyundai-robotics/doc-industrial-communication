# 3.2 EtherCAT Master IO错误处理

这是解决EtherCAT Master IO设置中可能发生的主要错误的方法。

<br>

![[图 3.2-1 EtherCAT Master 状态]](<../_assets/3-ethercat-master-io/2-Error/image_1.png>)

{% hint style="info" %}
\.      请确认LAN电缆的连接状态。

\.      请确认Adapter Device的电源是否开启。

\.      请确认其设置是否与Remote IO Module的IO组合相同。
{% endhint %}
